# 🏠 House Price Prediction

## Project Overview

House Price Prediction is an end-to-end Machine Learning
project that predicts the estimated price of a house based
on its property features.

The project demonstrates the complete workflow from dataset
preparation and preprocessing to model training, evaluation,
model saving and Streamlit deployment.

## Objective

The objective is to build a Linear Regression model that
predicts house prices using property-related features.

## Dataset

This project uses a sample/synthetic house-price dataset
created for demonstration and educational purposes.

The dataset contains the following columns:

- area
- bedrooms
- bathrooms
- floors
- parking
- age
- price

The target variable is `price`.

## Data Preprocessing

The following preprocessing steps were performed:

1. Loaded the dataset using Pandas.
2. Checked for missing values.
3. Checked for duplicate records.
4. Removed duplicate rows.
5. Removed rows containing missing values.
6. Selected relevant features for model training.

## Features

The model uses:

- Area in square feet
- Number of bedrooms
- Number of bathrooms
- Number of floors
- Parking spaces
- Property age

## Machine Learning Model

Linear Regression was used for house price prediction.

The dataset was divided into training and testing sets using
an 80:20 split.

## Model Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

### Evaluation Results

Add the values generated by `train_model.py` below:

- MAE: 308,326.57
- MSE:141,898,385,912.17
- RMSE: 376,694.02
- R² Score: 0.9945

## Model Saving

The trained model is saved using Joblib:

`model/house_price_model.pkl`

## Streamlit Application

The Streamlit application allows the user to enter:

- Area
- Bedrooms
- Bathrooms
- Floors
- Parking
- Property age

The application then displays:

- Estimated house price
- Input summary
- Prediction interpretation

## Interpretation

The model estimates house prices from the selected property
features.

The R² score indicates how well the model explains the variation
in house prices on the test dataset.

The prediction is an estimate and is not a guarantee of the
actual market price.

## Limitations

- The dataset is a sample/synthetic dataset.
- Real-world house prices depend on many additional factors.
- Location can have a significant effect on property prices.
- Market conditions can change over time.
- Linear Regression may not capture complex relationships.
- The predicted value should not be treated as an actual
  property valuation.
